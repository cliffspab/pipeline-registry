# Pull integrity

Every part carries a build tag; parts of one build carry one tag. A tag diverging from its siblings is a bad pull — re-fetch with a modified address, appending any query string, and compare. Report the divergence only where it survives the re-fetch.

Two further conditions read as a bad pull on the same test: content contradicting an event held as resolved, and a placeholder standing against a date already passed.

A figure supplied by the operator — commit ID, character count, budget — is the operator's evidence. Cite it as theirs; do not restate it as a desk verification.
