# Cold reconstruction

This procedure rebuilds the mechanism without the original workspace or chat
history.

## Acquire

```powershell
git clone https://github.com/cliffspab/pipeline-registry.git
Set-Location pipeline-registry
git status --short --branch
git log -1 --oneline --decorate
```

Read `PORTABILITY/README.md`, `bootstrap/AGENTS.md`,
`Blueprint/VERSION.txt`, `CHANGELOG.md` and `COMMITS-PENDING.md`.

## Install

Install Python 3.12 or newer, Git, authenticated GitHub CLI and rclone. Install
the pinned Python dependencies:

```powershell
python -m pip install PyYAML==6.0.3 python-docx==1.2.0
```

Restore rclone remotes named `pCloud:`, `GDrive:` and `onedrivebkp:`.
Never place their credentials in the project.

## Prove the clone

```powershell
python Blueprint/build.py --check --release
python Blueprint/build_human_volume.py --check
python PORTABILITY/verify_portability.py --live
python bootstrap/distribute_blueprint.py --preflight
python bootstrap/shift.py --check
```

All commands must pass. If Shift has not yet been created on the recovery
machine, run `python bootstrap/shift.py` once, then rerun its check.

## Recreate the workspace shell

Copy `bootstrap/AGENTS.md` and `bootstrap/00_START-HERE.md` to the parent
workspace if that shell is desired. The repository remains self-contained:
`push.bat` invokes its build, pending-record and distribution tools directly
from the clone.

## Acceptance

A cold reconstruction succeeds when the clean clone reproduces generated bytes,
the Word witness matches, the portability manifest passes, GitHub access works
and all three rclone remotes pass preflight. Do not test publication merely to
prove recovery; the supervisor retains the guarded `PUSH` decision.
